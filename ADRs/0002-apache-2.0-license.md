# ADR-0002: Apache License 2.0

- Status: Accepted
- Date: 2026-07-15
- Scope: this repository

## Decision

UniMath is Apache-2.0: `LICENSE`, `NOTICE`, and `CONTRIBUTING.md` (DCO) ship
in the repo root. Apache-2.0 grants an explicit patent license alongside
copyright. `NOTICE` records the bundled MIT dependencies (NimContracts,
optional nimsimd) and the Apache-2.0 UniAccurate dependency.
